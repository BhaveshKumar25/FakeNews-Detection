Key Capabilities & Features

TF-IDF & Logistic Regression

Trained on thousands of real-world articles for high-speed, lightweight classification with mathematical interpretability.

Regional Language Pipeline

Native Hindi support with automatic language detection, translation safeguards, and transparent processing notification.

Safe URL Article Extraction

Safely extracts text, domain, and publication metadata from news links with SSRF protection and user editing.
